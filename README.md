# بیتا — حضور، تولید و بهره‌وری نیروها

وب‌اپ (PWA) برای اندروید و iOS. بک‌اند روی Supabase (پروژهٔ `bita-workforce`).

## راه‌اندازی سریع (بدون نصب هیچ چیز)

پوشهٔ `dist` آماده است. یکی از این راه‌ها:

1. **Netlify Drop:** به app.netlify.com/drop بروید و پوشهٔ `dist` را بکشید و رها کنید. لینک آماده است.
2. **لیارا / آروان (سرور ایرانی):** یک «برنامهٔ استاتیک» بسازید و محتوای `dist` را آپلود کنید.
3. **هر هاست معمولی (cPanel):** محتوای `dist` را در `public_html` بریزید.

> سایت حتماً باید با **https** باز شود تا قابلیت نصب روی گوشی کار کند.

## ورود اول

- نام کاربری: `admin`
- رمز موقت: در پیام تحویل آمده — بعد از ورود از بخش «حساب» عوضش کنید.

## ساخت دوباره از سورس

```bash
npm install
npm run build   # خروجی در dist
npm run dev     # اجرای محلی
```

## ساختار

- `src/pages/Today.jsx` — صفحهٔ نیرو: ورود/خروج، شروع/پایان عملیات
- `src/pages/Reports.jsx` — گزارش‌ها، نمودار روند، خروجی اکسل
- `src/pages/Admin.jsx` — وضعیت زنده، نیروها، مراحل، اصلاح ثبت‌ها
- `src/lib/calc.js` — فرمول‌ها

## فرمول‌ها

- بهره‌وری = ۱ − (زمان واقعی − زمان استاندارد) ÷ زمان استاندارد
  (زمان استاندارد = زمان استاندارد هر واحد × تعداد)
- کارکرد مؤثر = مجموع زمان عملیات ÷ مجموع زمان حضور

همهٔ زمان‌ها با **ساعت سرور** ثبت می‌شوند (منطقهٔ زمانی تهران)، نه ساعت گوشی.

## دیتابیس

جدول‌ها: `profiles`، `stages`، `attendance`، `operations` با RLS. ثبت ورود/خروج و عملیات فقط از طریق توابع `clock_in`، `clock_out`، `start_operation`، `end_operation` انجام می‌شود. ساخت و حذف کاربر و تغییر رمز با Edge Function `admin-users`. تاریخچهٔ تغییرات در بخش Migrations داشبورد Supabase هست.
